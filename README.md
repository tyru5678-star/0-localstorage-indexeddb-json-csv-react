# 전담교사 시간표 도우미

React + Vite로 만든 정적 웹앱입니다. 서버, 로그인, 데이터베이스 없이 각 사용자 브라우저의 `localStorage`에 데이터가 저장됩니다.

## 실행 준비

### 가장 쉬운 방법

1. `처음실행.bat` 파일을 더블클릭합니다.
2. 검은 창이 열리면 기다립니다.
3. 브라우저에서 `http://localhost:5173` 을 엽니다.
4. 다음부터는 `실행만하기.bat` 파일을 더블클릭하면 됩니다.

검은 창은 앱이 실행되는 동안 닫지 마세요.

### 명령어로 실행하는 방법

1. Node.js를 설치합니다.
   - https://nodejs.org 에서 LTS 버전을 설치하면 됩니다.
2. 이 폴더에서 터미널을 엽니다.
3. 아래 명령어를 순서대로 입력합니다.

```bash
npm install
npm run dev
```

4. 터미널에 표시되는 주소를 브라우저에서 엽니다.
   - 보통 `http://localhost:5173` 입니다.

## 파일 구조

```text
index.html          브라우저가 처음 여는 HTML 파일
package.json        설치할 도구와 실행 명령어 목록
src/main.jsx        React 화면과 localStorage 저장 로직
src/styles.css      화면 디자인
README.md           실행 방법 설명
```

## 현재 구현된 기능

- 좌측 메뉴 레이아웃
- 홈, 주간 계획, 기초 설정, 교사 관리, 교과 관리, 교과 배정 페이지
- 데이터 추가, 수정, 삭제 기본 UI
- 브라우저 `localStorage` 자동 저장
- JSON 백업 저장과 불러오기
- 교사별 수업 가능 시간 체크
- 주간 계획별 교과 배정 설정
- 주간 계획별 일회성 외부강사 수업 추가

## 아직 만들지 않은 기능

- 자동 시간표 생성 알고리즘
- CSV 또는 엑셀 내보내기
- 구글 시트 연동

## 데이터 저장 위치

입력한 데이터는 현재 브라우저의 `localStorage`에 저장됩니다. 같은 컴퓨터라도 다른 브라우저를 사용하면 데이터가 보이지 않을 수 있습니다.
